# 🎮 Tic-Tac-Toe (Triliza) — C++

A colorful, console-based Tic-Tac-Toe game developed in **C++**. Play against a friend or challenge the computer across multiple difficulty levels.

## ✨ Features

- 👥 **Two-player mode** — Play locally with another player.
- 🤖 **Easy AI** — Challenge the computer at an easier difficulty.
- 🧠 **Hard AI** — Test your skills against a more challenging computer opponent.
- 🎨 **Colored terminal interface** — Distinct colors for X, O, the board, and game messages.
- 📊 **Game statistics** — Track player wins, computer wins, and draws.
- ✅ **Input validation** — Handles invalid and occupied board positions.
- 🔄 **Replay and navigation** — Play another round or return to the main menu.
- 🧩 **Modular code structure** — Organized functions for board management, gameplay, and statistics.

## 🕹️ Game Modes

1. Two Players
2. Play Against Computer — Easy
3. Play Against Computer — Hard
4. View Statistics
5. Exit

## 🛠️ Built With

- **C++**
- Standard C++ Library
- ANSI escape codes for terminal colors

## 🚀 Getting Started

### Prerequisites

- A C++ compiler, such as GCC or MinGW.
- A terminal or command prompt.

### Compile the Project

Open a terminal in the project directory and run:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o tic-tac-toe
```

### Run the Game

**Windows PowerShell:**

```powershell
.\tic-tac-toe.exe
```

**Linux / macOS:**

```bash
./tic-tac-toe
```

> **Note:** Terminal color support may vary depending on your terminal configuration.

## 📋 How to Play

1. Start the game.
2. Select a game mode from the main menu.
3. Choose an available board position from **1 to 9**.
4. The first player to align three symbols horizontally, vertically, or diagonally wins.
5. If all positions are filled without a winner, the round ends in a draw.
6. Review the statistics and play again!
